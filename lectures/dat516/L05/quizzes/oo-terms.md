Identify the correct definition for each of these OO terms.

# encapsulation

- A: creating many objects from the same class
- B: grouping together data and the operations on it
- C: breaking up long code into separate functions

# class

- A: collection of objects grouped together
- B: template describing the data and behaviour of objects
- C: function that returns objects

# object

- A: collection of classes grouped together
- B: a generic data type
- C: instance of a class

# instantiation

- A: creating a new object from a class
- B: adding a method to an existing object
- C: defining a new class

# instance variable

- A: variable belonging to a particular object
- B: variable shared by all objects of a class
- C: a parameter passed into a method

# method

- A: alternative name for a function
- B: variable stored inside an object
- C: function that belongs to a class or object
