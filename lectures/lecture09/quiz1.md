# Quiz 1: requests

## Q1: Simple GET

What status code do we get from:

GET https://www.cse.chalmers.se/~aarne/

## Q2: Adding query string

What status code do we get from:

GET https://www.cse.chalmers.se/~aarne/?foo=bar

## Q3: Changing path

What status code do we get from:

GET https://www.cse.chalmers.se/~foo/?aarne=bar

## Q4: Changing method

What status code do we get from:

PATCH https://www.cse.chalmers.se/~aarne/

## Q5: Changing domain

What status code do we get from:

GET https://www.cse.chalmers123.se/~aarne/
