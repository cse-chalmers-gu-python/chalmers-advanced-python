### 1.3. A better regex for email addresses

See if you can build a regex for the following rules? 

1. An email address must have a user part, an `@` sign, a domain, a `.`, and a

2. User part: 
    1. The user part must start with a letter or digit.
    2. After its first character, the user part may contain letters, digits, dots (`.`), underscores (`_`), and hyphens (`-`).
    3. In general, the use part must be between 4-16 characters .

3. The `@` sign separates the user part from the domain.

4. Domain part: 
    1. The domain part must start with a letter or digit.
    2. After its first character, the domain part may contain letters, digits, underscores (`_`), and hyphens (`-`).
    3. The domain part can be between 1-256 characters.

5. The domain must be followed by a literal dot (`.`).

6. Top-level domain (tld) part 
    1. tld must contain at least two letters, but not more than 4 letters.
    2. Only upper and lower case letters are alloed in tld.
    3. It is valid to not have tld, in which case the `.` after domain shall not be present.

### 1.4. Extract named email components and create structured data 

Create a dictionary entry for each domain where key is domain and values are all users in that domain 

create **named capture groups** to store parsed data 

```python
username = r"(?P<name>[A-Za-z0-9][A-Za-z0-9._-]{3,15})"
domain = r"(?P<domain>[A-Za-z0-9][A-Za-z0-9_-]{1,255})"
tld = r"(?P<tld>[\w]{2,4})"

pattern = username + "@" + domain + r"(\." + tld + r")?" 
```

**`?P<name>`** create a named capture group with the name given in `< >`. If a match occurs, it is stored as named group

**use named groups to create data structure**

## 2. Processing web url/uri 

A URI is a web address that tells a program where a resource is and how to access it. each uri has some parts, like protocol, host, port, path etc. Each part has certain value. For example, in the following case, protocol's value is `https`, and query's value is `q=regex&page=2`

```text
https://example.com:8080/search?q=regex&page=2#results
```

- `protocol`: **https** tells the program which communication rules to use.
- `host`: **example.com** identifies the server that hosts the resource.
- `port`: **8080** is optional and identifies a specific service on that server.
- `path`: **/search** identifies a resource or location on the server.
- `query`: **q=regex&page=2** is optional and sends parameters to the resource.
- `fragment`: **results** is optional and identifies a location within the returned resource.


Create a URI pattern with named groups:

The URI must follow these rules:

1. `protocol` must be either `http` or `https`, followed by `://`.
2. `host` must contain one or more letters, digits, dots, or hyphens.
3. `port` is optional. When present, it starts with `:` and contains one or more digits.
4. `path` is optional. When present, it starts with `/` and cannot contain whitespace, `?`, or `#`.
5. `query` is optional. When present, it starts with `?` and cannot contain whitespace or `#`.
6. `fragment` is optional. When present, it starts with `#` and cannot contain whitespace.

```python
uri_pattern = (
    r"(?P<protocol>https?)://"
    r"(?P<host>[A-Za-z0-9.-]+)"
    r"(:(?P<port>\d{1,5}))?"
    r"(?P<path>/[^\s?#]*)?"
    r"(\?(?P<query>[^\s#]*))?"
    r"(#(?P<fragment>\S*))?"
)
```

| Pattern component | Meaning |
|---|---|
| `(?P<protocol>https?)` | Captures `http` or `https` as `protocol`; `s?` makes the `s` optional. |
| `://` | Matches the literal protocol separator. |
| `(?P<host>[A-Za-z0-9.-]+)` | Captures one or more letters, digits, dots, or hyphens as `host`. |
| `(:(?P<port>\d{1,5}))?` | `:` followed by 1–5 digits which are also captured as `port` group. the ?  in the end  means 0 or 1 occurance  |
| `(?P<path>/[^\s?#]*)?` | path starting with `/` followed by 0 or more characters which cannot contain whitespace, `?`, or `#`. note the use of `^`, when inside [ ] it means negation |
| `(\?(?P<query>[^\s#]*))?` | `?` followed by query text which cannot contain spaces or #. note the use of \?, which means literal match of `?`. If we do not escape `?` then it has special meanings|
| `(#(?P<fragment>\S*))?` | `#` followed by the fragment which contains 0 or more non-space characters. |
