```python
class TestGraph(unittest.TestCase):

    def setUp(self):
        # Create an empty graph instance to test 
        self.graph = Graph() 

    def test_new_empty_graph_has_no_vertices(self):
        # We do not use simple assert statements now. unittest library provides several advanced assert statements, for example assertEqual which we use here 
        self.assertEqual(self.graph.vertices(), set())
```

# 3. Testing `read_directory`

The `read_directory()` function depends on the filesystem, so we use `tempfile.TemporaryDirectory()` to create a small, controlled directory that is removed automatically after the test. This function is provided by the Python standard library `tempfile` and does not need any installation. Similarly, we import `Path` to read directory name which `TemporaryDirectory` created for us. 

1. Start by testing the simplest case: an empty directory. Note the contract of our `read_directory`. It returns `list[tuple[str, list[str]]]`. So, if we have an empty directory which is named `test`, we expect `['test': []]` to be returned. 

In this case, the directory name is retrieved from `TemporaryDirectory` with `Path(dir).name` and stored in `root`. 


```python
from tempfile import TemporaryDirectory as tempdir
from pathlib import Path

class TestReadDirectory(unittest.TestCase):
    def test_empty_directory(self):
        with tempdir() as dir:
            root = Path(dir).name
            result = read_directory(dir)
            self.assertEqual(result, [(root ,[])])
```

Run tests and observe the output. The tests are passed because the expected result contains:

- the directory's name as the root;
- an empty list because the directory has no files or subdirectories.

2. Add a file and a subdirectory, then check that `read_directory()` reports both. 

Note here how we create a new file and a sub directory in our tempdir. The statement `file = (root / 'file.txt')` creates a `Path` object on which `file.write_text` actually creates a file. Similarly, `subdir = (root / 'sub_dir')` creates a `Path` object, and `mkdir()` actually creates the subdirectory. Though, all this directory structure lives only within `with` block. 

```python
def test_with_file_and_subdir(self):
    with tempdir() as dir:
        root = Path(dir)
        file = (root / 'file.txt')
        file.write_text('example text')
        subdir = (root / 'sub_dir')
        subdir.mkdir()

        result = read_directory(root)

        self.assertEqual(
            result, 
            [(root.name, [subdir.name, file.name]),
                (subdir.name, [])]
        )
```


Note: This test is flawed. It may work with this example, but may fail with actual directory listing from OS. The reason is the order of files and folders. An os may return files and folders in a different order for various calls. Hence, comparing recieved output with a list of expected directory structure will not work. 

**Think** how you can solve this problem and write a reliable test.
