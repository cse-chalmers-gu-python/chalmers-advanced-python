## 2. Testing `Tree`

Now we test our `Tree` class. Remember that `Tree` is a special form of `Graph`, therefore we expect that our `Tree` is mostly correct (based on assumption that we have already tested `Graph` thoroughly).

1. Create `setUp()` method, and test if initial tree instance is as expected:

    ```python
    class TestTree(unittest.TestCase):
        def setUp(self):
            self.tree = Tree("root")

        def test_initial_tree_contains_only_root(self):
            self.assertEqual(self.tree.vertices(), {"root"})
            self.assertEqual(self.tree.edges(), set())
            self.assertEqual(self.tree.leaves(), {"root"})
    ```

2. What additional tests should be added for `Tree`? Think about the requirements and constraints that make trees different from graphs. To start with, each of these deserves it own test method:

    1. Creating a tree without root is not allowed
    2. Creating a tree with empty root `""` is not allowed
    3. Adding a vertex is not allowed
    4. Root does not have a parent

    <details markdown="1">
    <summary>Show solution</summary>

    ```python
    def test_create_without_root_not_allowed(self):
        with self.assertRaises(TypeError):
            Tree()

    def test_create_empty_root_not_allowed(self):
        with self.assertRaises(ValueError):
            Tree("")

    def test_add_vertex_not_allowed(self):
        with self.assertRaises(NotImplementedError):
            self.tree.add_vertex("M")

    def test_root_has_no_parent(self):
        self.assertTrue(
            all(
                "root" not in children
                for children in self.tree._adjdict.values()
            )
        )
    ```

    </details>

## 3. Testing `read_directory()`

The `read_directory()` function depends on the computer's filesystem.

1. To be able to test this function in a reproducible way, we want to create a temporary directory specifically for use in the tests, which is then removed automatically afterwards.
    For this we can use the Python standard library `tempfile` and its class [`TemporaryDirectory`](https://docs.python.org/3/library/tempfile.html#tempfile.TemporaryDirectory).
    We can use this together with [`pathlib.Path`](https://docs.python.org/3/library/pathlib.html#pathlib.Path) to help us get folder name for the temporary directory, like so:

    ```python
    from tempfile import TemporaryDirectory
    from pathlib import Path

    with TemporaryDirectory() as dir:
        print("Full path:", dir)
        print("Folder name:", Path(dir).name)
    ```

2. Start by testing the simplest case: an empty directory. The type signature of `read_directory()` says that it returns `list[tuple[str, list[str]]]`. So, if we have an empty directory named `test` we should expect a return value of `[('test', [])]`.

    ```python
    class TestReadDirectory(unittest.TestCase):
        def test_empty_directory(self):
            with TemporaryDirectory() as dir:
                root = Path(dir).name
                result = read_directory(dir)
                self.assertEqual(result, [(root ,[])])
    ```

    Run the test and observe the output. It should passe because the result contains:

    - the directory's name as the root
    - an empty list because the directory has no files or subdirectories

3. Add a test which creates a file inside the temporary directory.
    The statement `file = (root / 'file.txt')` creates a new `Path` object, but doesn't create the file itself.
    It is the call to `file.write_text()` which actually creates it.

    ```python
    def test_with_file(self):
        with TemporaryDirectory() as dir:
            root = Path(dir)
            file = (root / 'file.txt')
            file.write_text('example text')

            result = read_directory(dir)

            self.assertEqual(
                result, 
                [(root.name, [file.name])]
            )
    ```

4. Create a similar test, which adds two subdirectories to the temporary folder.
    To create a subdirectory you can use:

    ```python
    subdir = (root / 'sub_dir')
    subir.mkdir()
    ```

    <details markdown="1">
    <summary>Show solution</summary>

    ```python
    def test_with_subdirectories(self):
        with TemporaryDirectory() as dir:
            root = Path(dir)
            subdir1 = (root / 'sub_dir_1')
            subdir1.mkdir()
            subdir2 = (root / 'sub_dir_2')
            subdir2.mkdir()

            result = read_directory(dir)

            self.assertEqual(
                result, 
                [
                    (root.name, [subdir1.name, subdir2.name]),
                    (subdir1.name, []),
                    (subdir2.name, [])
                ]
            )
    ```

    **Note**: This test is flawed! It may work with this example, but may also fail because the subdirectories are listed in the opposite order:

    ```plain

    + [('tmpzehi3wpz', ['sub_dir_1', 'sub_dir_2']),
    -  ('sub_dir_2', []),
    ?            ^

    +  ('sub_dir_1', []),
    ?            ^

    -  ('sub_dir_1', [])]
    ?            ^

    +  ('sub_dir_2', [])]
    ?            ^
    ```

    This order should not matter however. So think about how the test can be improved to make it more reliable.

    </details>
